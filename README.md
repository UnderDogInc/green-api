# Тест green API

## Описание
MVP для отправки и получения текстовых сообщений. Тк не было возможности узнать как выглядит MAX, для создания UI взял их библиотеку `@maxhub/max-ui`

Также отправка сообщений реализована через Telegram вместо MAX

## Стек
- **React 19**
- **TypeScript**
- **TanStack Router**
- **TanStack Query**
- **Tailwind CSS 4**
- **MAX UI**

## Функционал

- Чат с пулингом
- Отправка текстовых сообщений в Telegram
- Получение сообщений из Telegram
- 
## Запуск проекта
Установите зависимости:

```bash

pnpm install
```

Запустите приложение в режиме разработки:

```bash
pnpm dev
```

Для production-сборки:

```bash
pnpm run build
```
